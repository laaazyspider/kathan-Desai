# Kathan Desai — Academic Website Starter

A responsive, single-page academic website starter for an astrophysics PhD researcher.

## Preview locally
1. Extract the ZIP file.
2. Open `index.html` in a web browser.

The page is built with plain HTML, CSS, and JavaScript. No build tools are required.

## Before publishing
- Replace the placeholder email and academic-profile text in `index.html`.
- Add your verified publications/preprints in the Publications section.
- Add your PDF CV to this folder and name it `cv.pdf`.
- Review the biography, degree details, and research interests for accuracy.
- If you want a portrait, it can be added to the About section.
- The design currently loads Google Fonts from the web; system fallbacks are included.

## Publishing
You can publish this folder using GitHub Pages or another static website host. For GitHub Pages, create a repository, upload the contents of this folder, and enable Pages in the repository settings.
